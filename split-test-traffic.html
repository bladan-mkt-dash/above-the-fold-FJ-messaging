Landing page views by variant

Traffic campaigns are paid to get people onto the site. Landing page views are the outcome. Link clicks are the auction metric.

Y-axis: landing page views. Source: Meta actions.landing_page_view.

Link CTR vs cost per landing page view

V1 wins the click rate. V3 wins the visit. Those are not the same contest.

Y-axis: link CTR (%).

Y-axis: dollars per landing page view.

V1 — highest CTR, fewest visits

0.613% link CTR is a real win vs V2 and V3 (p < 0.001). Only 9 of 293 link clicks became a landing page view (3.1%). Cost per visit $13.89.

V2 — cheapest reach, weakest click

Lowest CPM ($1.44) and most impressions, especially Sep 29 (56k impressions for $23). Link CTR 0.309%. 16 landing page views.

V3 — winner for this objective

Most link clicks (344), most landing page views (30), lowest CPC ($0.40), lowest cost per visit ($4.34). LPV rate vs V1 is significant (p = 0.003).

Setup notes

Shared copy: “Discover a Different Kind of Care” / “Looking for a different approach to your health?” Destination is http (not https) fivejourneys.com. Ad set names say women 35–55; the API targeting is women, US, ages 18–65. Advantage+ placements (feed, stories, reels). Only 55 of 898 link clicks became a landing page view (6.1%). That gap is a tracking or click-quality problem, not a sample-size problem.
